## Senior Infrastructure Operations Engineer – SQL Server & Automation
**XYZ Denmark | Albertslund**

This role is the north star for this entire study guide. Every topic maps back to a specific requirement in this job description.

> [!info]
> **Target Role:** Senior Infrastructure Operations Engineer (SQL Server & Automation) at XYZ Denmark
> **Team:** Infrastructure Operations — supporting XYZ across Denmark, Faroe Islands, Greenland, and border stores in Germany
> **On-call:** 24/7 critical duty rotation (Danish required)

### Key Responsibilities

| Area | What It Means for the Interview |
|------|----------------------------------|
| Operation & maintenance of business-critical SQL Server platforms in 24/7 enterprise environment | Daily health checks, incident response, stability-first mindset |
| Performance tuning, capacity optimization, automation | Wait stats, Query Store, execution plans, index tuning, automated monitoring |
| High Availability & Disaster Recovery | Always On Availability Groups, sync/async replicas, failover, quorum, DR testing |
| Infrastructure modernization & Azure cloud initiatives | Azure SQL DB, Managed Instance, migration strategies, hybrid architectures |
| Migrations, upgrades, improvement projects | DMA, compatibility levels, side-by-side vs in-place upgrades, rollback planning |
| Security, compliance, robust operational processes | TDE, least privilege, auditing, service accounts, backup encryption |
| Troubleshooting, incident management, technical sparring | Systematic troubleshooting methodology, clear communication, RCA documentation |

### Candidate Profile

- Solid SQL Server DBA experience in a large operational/enterprise environment
- Strong T-SQL, performance tuning, operations, and security skills
- Experience with HA/DR in complex environments
- Knowledge of virtualized platforms and Azure infrastructure
- Structured, proactive approach to automation and optimization
- Good communicator with technical and non-technical stakeholders

### Interview Mindset

> "I keep platforms stable, troubleshoot without guessing, protect data with tested backups, design HA/DR around business RPO/RTO, automate repeatable tasks, and communicate clearly during incidents."
