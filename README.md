# SQL Server DBA Interview Preparation

Comprehensive study guide for **Senior Infrastructure Operations Engineer (SQL Server & Automation)** interviews. Covers 24/7 enterprise operations, performance tuning, HA/DR, security, Azure, and real-world consolidation scenarios.

## Study Companion Files

- `XYZ_SQL_Server_DBA_Beginner_Prompt_Bank.md` — AI-tutor prompts for structured learning
- `XYZ-JD.txt` — Original job description

## How to Use

Open `index.html` in any browser for the full interactive study guide with:
- 23 chapters with searchable content
- Dark/light theme toggle
- Mobile-responsive layout
- T-SQL examples with syntax highlighting
- Real-world scenarios and interview answers

### Build (if editing source Markdown)

```bash
npm install
npm run build    # regenerates index.html from src/*.md
npm run preview  # serves the site locally
```

## Deploy

Push to GitHub and enable **GitHub Pages** from the root of the `main` branch — the site is ready to serve.
